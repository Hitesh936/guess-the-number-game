# 🎮 Guess the Number (Python Game)

This is a simple **Guess the Number** game built with Python.

The computer randomly selects a number between 1 and 99, and the player has to guess it. The program gives feedback whether the guess is too high or too low.

---

## 🚀 How to Run

1. Make sure you have **Python 3** installed.
2. Run the script:

```bash
python guess_the_number.py
